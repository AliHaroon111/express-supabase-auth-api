# FlyRank Auth API

Secure API for FlyRank Internship · Backend Track · W2 · A4 — Auth: Login & protect.

Built with Node.js, Express, and Supabase Auth. Supabase manages accounts, password hashing, and JWT
signing; this server verifies tokens and guards protected routes.

> Work in progress — this README is filled in fully at Stage 6 (setup instructions, run command,
> endpoint/auth table, and Swagger screenshot).

## Stack

- Node.js + Express
- Supabase Auth (Identity Provider)
- dotenv for environment variables
